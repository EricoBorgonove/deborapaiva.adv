# Remoção dos dados de sorteio

Em 19/11/2026, a consulta pública da API do GitHub informou zero forks de
`EricoBorgonove/deborapaiva.adv`. O commit antigo `1519c47` ainda respondeu HTTP 200.
Isso não comprova ausência de downloads, clones privados ou caches externos.

Os arquivos pessoais e o acesso de sorteio foram retirados do histórico publicado.
Os backups de recuperação são privados e externos ao repositório. Não os publique.
